# wrence-store

A modern **e-commerce web application focused exclusively on bags**, built with React and designed with a clean, professional shopping experience in mind.

The project focuses on providing customers with a simple way to browse products, view product details, manage their cart, and proceed through the shopping process.

---

## ✨ Features

* **Product browsing** — Explore available bags through a clean product interface.
* **Product details** — View individual product information before making a purchase.
* **Shopping cart** — Add, remove, and manage products before checkout.
* **Favorites** — Save products for easier access later.
* **Search** — Quickly find products within the store.
* **Responsive design** — Optimized for desktop, tablet, and mobile screens.
* **Navigation & dropdowns** — Structured navigation for easy access to different sections of the store.
* **Checkout flow** — Designed to support a straightforward purchasing experience.
* **Customer support section** — Easy access to important customer-service pages and information.

## 🚀 Getting Started

To run the project locally, clone the repository:

```bash
git clone https://github.com/lawrenceoguguom/wrence-store/
```

Navigate into the project directory:

```bash
cd wrence-store
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎨 Design

The interface is intentionally designed around a **clean and understated visual style**, with emphasis on:

* Clear product presentation
* Simple navigation
* Consistent spacing and typography
* Minimal visual clutter
* Responsive layouts
* Easy-to-use shopping interactions

The goal is to make the products the focus while keeping the overall experience modern and professional.
